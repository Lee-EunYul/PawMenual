# PAWMENUAL
오늘의 반려견 케어 결정을 빠르게 도와주는 맞춤형 **반려견 생활 관리 웹앱**입니다.
프로필 기반 식생활 가이드, 건강 상태 기록, 위치 기반 주변 동물병원 안내, 훈련 기록을 한곳에서 관리할 수 있도록 만든 프로젝트입니다.

## 1) 프로젝트 한 줄 소개

- **무엇을 해결하나요?**: 반려견 식사/건강/훈련을 따로 기록하면서 관리가 분산되는 문제
- **어떤 방식으로 해결하나요?**: 프로필 기반 맞춤 안내 + 위치 기반 병원 조회 + 통합 기록 관리
- **프로젝트 성격**: 단일 프론트엔드(SPA) 기반 반려견 케어 서비스

## 2) 어떤 앱인가요?

- 웹에서 바로 사용하는 반려견 맞춤 케어 서비스
- 반려견 정보를 한 번 입력하면 식생활/건강/훈련 화면에 맞춤 정보가 연동되는 구조
- 로컬 저장소 기반으로 가볍게 기록/조회 가능하고, Azure Static Web Apps로 배포된 구성

## 3) 핵심 기능

### 3-1. 프로필 기반 맞춤 케어

- 강아지 이름, 나이, 몸무게, 주식 타입(건식/습식/혼합), 특이사항 입력
- 프로필 저장 후 홈/식생활/훈련 화면에서 공통으로 활용

### 3-2. 예방접종·건강 일정 관리

- 프로필에 기반하여 필요한 예방접종 지남, 임박, 예정에 나누어 안내
- 필요한 예방접종를 체크리스트로 제시

### 3-3. 식생활 맞춤 가이드

- 상황(식욕 저하, 건식 거부 등) 선택 기반 급여 방향 안내
- 반려견 조건에 맞춘 추천 방향과 제품 후보 제시
- 식사 반응(좋아요/보통/거부) 기록 저장

### 3-4. 건강 상태 기록 + 주변 동물병원 조회

- 증상/체크 항목 선택 후 건강 요약 및 주의 단계 제공
- 현재 위치 기반으로 주변 동물병원 조회 및 거리순 정렬
- 조회 결과를 건강 기록과 함께 저장

### 3-5. 반응형 훈련 가이드

- 훈련 결과(성공/실패)에 따라 다음 액션 분기
- 실패 원인 선택 시 재시도 플랜 제시
- 훈련 이력 저장

### 3-6. 통합 성장 기록 조회

- 식사/건강/훈련 로그를 타임라인으로 통합 조회
- 카테고리/날짜 필터로 기록 탐색

## 현재 위치 기반 동물병원 검색

건강 화면의 **현재 위치로 주변 병원 찾기**를 누르고 위치 권한을 허용하면,
브라우저가 최신 좌표를 감지하고 서버가 카카오 장소 API에서 동물병원을 검색합니다.
앱 안에 병원명, 직선거리, 주소, 제공된 전화번호를 가까운 순으로 표시합니다.
지도 링크는 개별 병원의 상세정보를 확인하는 보조 기능입니다.

로컬 `api/.env`에 아래 항목을 추가하세요. Azure OpenAI 키와는 별개의 카카오 REST API 키입니다.

```dotenv
KAKAO_REST_API_KEY=발급받은_카카오_REST_API_키
```

카카오 개발자 앱에서 장소 검색 API 사용 권한과 쿼터를 확인하세요.
키는 채팅, 프론트엔드 코드 또는 GitHub에 올리지 않습니다. 변경 후 `npm --prefix api run dev` 서버를 재시작합니다.
Azure 배포 시에도 같은 이름의 서버 환경변수를 등록해야 합니다.

검색 반경은 3/5/10/20km이며 최대 45개 결과를 조회합니다. 결과 없음, 위치 권한 거부,
위치 시간 초과, API 실패와 키 미설정을 구분해 안내합니다. 가상 병원 목록으로 대체하지 않습니다.
위치 정확도가 낮으면 오차를 표시합니다. 현재 좌표는 서버를 거쳐 카카오에 전송하며 직접 로그로 남기지 않습니다.
모든 병원의 누락 없는 표시나 실시간 영업 여부를 보장하지 않습니다. 실제 조회에는 유효한 카카오 키가 필요합니다.

## Azure OpenAI 식생활 추천 설정

AI 추천은 서버 API를 통해서만 호출합니다. 키를 `VITE_` 변수나 프론트엔드 코드에 넣지 마세요.
로컬 키 파일은 `api/.env`이며 Git에서 제외됩니다. 키를 채팅이나 GitHub에 올리지 마세요.

1. `api/.env`에 다음 값을 직접 입력합니다.

```dotenv
AZURE_OPENAI_ENDPOINT=https://YOUR-RESOURCE.openai.azure.com/
AZURE_OPENAI_API_KEY=YOUR-API-KEY
AZURE_OPENAI_DEPLOYMENT=YOUR-DEPLOYMENT-NAME
AZURE_OPENAI_API_VERSION=2024-10-21
PORT=7071
```

`AZURE_OPENAI_DEPLOYMENT`는 Azure에 생성한 모델의 **배포 이름**입니다.
키와 엔드포인트만으로는 호출할 수 없습니다. JSON 응답과 Chat Completions를 지원하는 배포가 필요합니다.

2. 프로젝트 루트에서 서버와 웹앱을 각각 다른 터미널로 실행합니다. Node.js 20 이상이 필요합니다.

```powershell
npm --prefix api install
npm --prefix api run dev
```

```powershell
npm --prefix app install
npm --prefix app run dev
```

3. 프로필에 견종, 나이(개월), 몸무게를 저장하고 식생활 화면에서 **AI 사료 추천 받기**를 누릅니다.
이름이나 위치는 전송하지 않습니다. 견종, 나이, 몸무게, 활동량, 음식 선호, 현재 사료 형태와 선택 상황이 Azure OpenAI로 전달됩니다.
AI는 급여 방식과 실제 사료 제품 후보를 함께 추천합니다. 제조사 공식 페이지로 실재를 확인한
제품 목록에서만 제품 ID를 선택하며, 이름과 링크는 서버가 제공하므로 임의의 제품이나 URL은 표시되지 않습니다.
등록 목록은 4개 브랜드, 10개 제품입니다.

| 브랜드 | 확인한 제품 |
| --- | --- |
| 로얄캐닌 | 미니 어덜트, 미디엄 어덜트, 미니 퍼피, 미니 어덜트 파우치 |
| 프롬 | 포스타 치킨 아 라 베지, 살몬 아 라 베지 |
| 파미나 | N&D 앤세스트럴 그레인 치킨 앤 포메그라네이트 어덜트 미니, 램 앤 블루베리 어덜트 미니 |
| 브릿 | 프리미엄 바이 네이처 센서티브 램, 케어 독 하이포알러제닉 어덜트 스몰 브리드 |

제품명과 대상 조건은 `api/food-recommendation/products.json`에서 관리합니다(확인일: 2026-11-01).
공식 해외 페이지도 사용하므로 국내 판매 여부나 지역별 제품 구성의 동일성은 보장하지 않습니다.
원료 요약은 전체 성분표가 아니며 제품명에 양고기·연어·하이포알러제닉이 포함돼도 단일단백질 또는 알레르기 안전성을 의미하지 않습니다.
제조사가 정확한 개월·체중 경계를 제공하지 않은 성견용 제품에는 보수적인 앱 후보 제한을 적용하고 이를 대상 설명에 명시했습니다.
프롬 전연령 제품은 이유 전 급여를 피하기 위해 앱에서 2개월 이상으로 제한합니다.
일부 제품만 비교하는 기능이며 실시간 재고, 가격, 전체 브랜드 비교 또는 의학적 적합성 검증은 아닙니다.
맞는 제품이 없으면 제품 후보 없이 급여 안내만 제공합니다. 질환과 알레르기는 수의사에게 확인하세요.

### 배포 환경

로컬 `.env`는 Azure에 업로드하지 않습니다. Azure Static Web Apps의 서버 환경변수 설정에
`AZURE_OPENAI_ENDPOINT`, `AZURE_OPENAI_API_KEY`, `AZURE_OPENAI_DEPLOYMENT`, `AZURE_OPENAI_API_VERSION`를 등록해야 합니다.
GitHub Actions의 API 경로는 `api`로 구성했습니다. 실제 배포와 서버 환경변수 등록은 별도로 진행해야 합니다.
배포 환경의 AI API는 로그인 사용자에게만 허용되며, 로컬 개발 서버는 본인 컴퓨터에서만 접근 가능합니다.
기존 정적 페이지와 기본 가이드는 로그인 없이 사용할 수 있습니다.

AI 호출은 버튼 클릭 시에만 실행되며 응답 토큰을 제한했습니다. Azure OpenAI 사용료는 별도입니다.
로그인만으로 과다 사용을 완전히 막지는 못하므로 공개 전 이용량 제한과 비용 알림을 추가하세요.
실패 시 기본 가이드를 유지하며 이를 AI 결과로 표시하지 않습니다.

검증 명령:

```powershell
npm --prefix api test
npm --prefix app run build
```
